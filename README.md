## Projeto em destaque

### [Retail Data Pipeline](https://github.com/Pablo-SVS/retail-data-pipeline)

Pipeline de dados públicos de varejo com Python, pandas e SQLite. Inclui validação de esquema, quarentena de registros, conciliação de valores, testes automatizados e exportações para Looker Studio.

**Etapas:** extração → tratamento → carga SQL → qualidade → consumo em BI.

O dashboard Looker Studio está em preparação. O repositório reúne o código, o dicionário de dados e as instruções para reproduzir o pipeline.
